## 1. 本轮行为与不变量

- 时、分、秒各列使用重复数据构造环形拨轮，滚动结束后回到中间副本；各列独立，不自动进位。
- 任务页同页区分音频、视频；视频编辑展示时间窗口、总时长和可折叠的播放条目。
- 手机横屏自动全屏，iPad 宽窗口可展示流程侧栏；全屏使用安全区内实际测量的视口。
- 全屏左下方原遍数区常驻 `2/49`，单行白字、局部半透明底，按视频画幅而非屏幕边缘定位。
  当前 856×482 素材的定位框为 `x=100,y=324,w=112,h=80`，下沿 404；
  以正文字幕从约 `y=408` 开始作为布局约束。坐标断言不能代替所有字幕帧的人工视觉确认。
- 片头、礼敬、片尾显示阶段名；流程结束显示“已结束”，不制造第 N+1 遍。
- 顶部操作和底部完整时间条播放时 3 秒隐藏，轻触可显示；常驻遍数不隐藏。
  暂停、忙碌、出错或读屏开启时保留控制。
- 数字代表公共流程正在进行的遍数，不是本机亲自完成量。暂停不冻结公共时间；恢复追平当前进度。
- 全屏复用同一个原生视频表面，只改变布局，不发送 load、seek 或 pause。
- 本轮未修改音频的“每首 N 个有效周期后执行四种模式”及同步计数资格规则。
  视频窗口仍为 `[开始时刻, 开始时刻+总时长)`，结束不回绕；运行实例使用冻结配置。

## 3. 二维码处理与时间轴校验

原始六份素材保留未修改。仅正文和最后一遍采用 FFmpeg delogo 对
`x=684,y=281,w=122,h=122` 局部插值；不裁全幅、不增加片头标题，不重编码 AAC、不淡化音频。
该方法并非原背景重建，可能留有模糊修补痕迹，仍需人工确认。
