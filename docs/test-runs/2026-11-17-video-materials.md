## 2. 实际处理与没有处理的内容

1. 原片头固定“49 遍”标题改为不含遍数的“ 大悲咒 / 星光播放器 ”标题卡；
   在原有时长内淡入、过渡，不缩短前导内容。
2. 固定数字区域 `(100,324,112,80)` 使用局部插值：
   正文和末遍整段，片头仅最后 0.24 秒附近。正文字幕区从约 y=408 开始，不作裁切。
   这不是恢复真实原背景，可能有修补痕迹。
3. 片尾内容保留，只在 76.36～76.72 秒对画面淡出。保留最后约 13 ms 超出视频轨的音频。
4. 每段声音两端各 221 个采样点（5.011 ms）微淡化，减少硬切样本跳变；
   不叠加两段、不加速、不移动内容、不删除换气或背景音。
5. 四段统一降低 2 dB，为原 AAC 解码超满刻度的峰值留余量。不做逐段响度拉平；
   末遍和片尾原本较轻的声音仍然保留。
6. H.264 Constrained Baseline、856×480、25 fps、SAR 320:321；
   AAC 44.1 kHz 双声道 / 192 kbps。1 秒 GOP，无 B 帧。
   都经过有损重编码，不能称为无损。
