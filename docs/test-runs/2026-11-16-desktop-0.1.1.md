## 代码核实与实现

电脑版原来已有三个时/分/秒 `<select>`，不需要再做手机拨轮。上一个提交已在手机同源任务定义、共享 TS 核心及 Rust 日历适配中支持星期；本次补齐桌面编辑器：

- 一至日七个多选按钮，默认全选，至少一天；状态可被读屏识别，支持键盘操作。
- 编辑时复制星期数组，取消不修改原数据，快照轮询不覆盖编辑草稿。
- 列表显示星期；开关冲突按“同时刻且星期交叠”判断；立即播放无视开关、时刻和星期。
- 显示名称、网页标题、原生窗口和 Tauri 产品名统一“星光播放器”；界面去掉技术预览字样。
- npm / Cargo / Tauri 及自身锁文件版本统一 `0.1.1`；UI 从配置读取名称和版本。
- 保留 identifier `org.starlightplayer.desktop.preview`、内部二进制名、数据文件与目录。

### 星期规则覆盖

- 穷举 127 种非空星期组合，每种都经过保存、启用、恢复，并对一周七天筛选，共 889 个日期断言。
- 原有测试复核旧数据每天迁移、重复/乱序归一化、非法/空星期、同刻交集冲突、自编辑、时间边界、15 分钟延迟与去重。
- 原生宿主测试使用隔离目录、真实系统时钟、实际 libmpv **null output**：
  - 在未选中的星期仍能手动播放未启用的任务。
  - 同时启用两个时刻相同但星期不交叠的任务，只有匹配星期的任务到点执行。
  - 只持久化一次自动认领，重启后星期与启用状态一致，且不会自动播放。
- 本轮原生记录位于忽略的 `apps/desktop/test-results/native-weekdays-1794844434333314000/`，并有同批 `native-controls-*`、`native-tasks-*`。它们是本机辅助证据，不是远端长期制品；测试代码可重复执行。正常用户数据目录未被测试使用。

### 界面回归

运行 `npm --prefix apps/desktop run web:dev`，以独立 Playwright CLI 会话打开 `http://127.0.0.1:1420`，再运行：

```sh
playwright-cli --session desktop-weekdays-011 run-code \
  --filename apps/desktop/scripts/ui-smoke.cjs
```

覆盖：

- 名称、页面标题、关于页 `v0.1.1`，无技术预览标签，唱片仍无文字。
- 新建默认每天，空选拒绝保存，周末选择与空格键切换，轮询不重置草稿。
- 保存后列表摘要和重开回显；取消不改变已保存星期。
- 同刻交叠禁止启用；改成不交叠允许启用；已启用任务改成有交叠时保存失败、草稿保留且不污染原数据。
- 420px 窄窗口下七个星期按钮均在容器内，无横向溢出，高度不小于 44px。
- 五种播放页尺寸：1120×780、800×800、1024×768、420×820、420×620。
- 既有数字输入/千分位、播放模式、同步锁进度、任务增删改/手动播放、关怀、后台偏好、诊断导出等交互。

截图生成在忽略目录 `output/playwright/desktop-*.png`。本轮 UI 结论依据 DOM、交互与几何断言，不声称已完成人工截图视觉审阅。
