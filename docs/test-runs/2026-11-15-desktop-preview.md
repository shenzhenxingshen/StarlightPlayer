## 2. UI 对齐手机版

自动化尺寸：1120×780、800×800、1024×768、420×820、420×620。

检查包括：

- 主色 `rgb(77,188,170)`、背景 `rgb(242,242,242)`；来自手机颜色模块。
- 无横向溢出；方/宽屏播放按钮与唱片圆心同水平线，左右控制/时间轴高度相等（2px 容差）。
- 方/宽屏数字在竖向进度左侧；竖屏当前遍数在横向进度上、重复遍数在下。
- 正整数校验、5,000,000 千分位、刷新不会覆盖尚未提交的输入。
- 模式/同步配置修改不发新任务命令、不清零。
- 同步时禁止拖动；不同步时键盘或整次拖动只发一个 seek，不在每次鼠标移动时发送。
- N=1 与 N>1 的数字显示规则；关怀隐藏、放大和持久化；选曲、四个导航入口。
- 3 个默认任务关闭、三行卡片无歌曲名；增删改、名称 30 字上限、23:59:59、切换曲目、5 百万遍、无效数字（含 `1e3`）拒绝。
- 保存不播放、编辑保留开关、关闭任务仍可立即播放并一次应用全部 4 项配置、删除确认/取消、不停止已开始的播放。
- 任务草稿不会被轮询覆盖，关怀隐藏任务；后台偏好、诊断导出交互、关怀重开保存。
- 自动恢复期间按钮允许暂停并取消重试，而不是把用户操作解释为再次播放。

截图仅为自动化产生的 mock UI 证据，未做人工像素审美验收。最终真实界面、读屏和键盘焦点仍需额外复核。

不能只看平均值：本轮存在约 0.5 秒的重启长尾。现有单条队列 EOF 重载方案仍需性能与声音实测，不能称为无缝播放。

`started` 是指令完成，`playback-restart` 是引擎通知，都不是第一帧音频实际到达耳朵。EOF 上的 `positionMs` 是此前进度采样，不应据此声称 A05 只有约 69.86 秒，也不能据此计算被吞掉的声音。
