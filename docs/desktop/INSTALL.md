# 星光播放器：电脑版安装与使用

当前源码版本：`0.1.1`，软件名称为“星光播放器”。本轮仅完成代码更新，尚未发布 `0.1.1` 安装包；以下现有安装包说明与历史文件名对应 `0.1.0`，不是手机版的新版本。去掉界面预览字样不代表签名、公证已完成。

安装包已收录全部 21 首音频、libmpv 播放引擎及平台所需的非系统播放库。Windows 包还内置完整 WebView2 离线安装程序。不需要自行安装 Node、Rust、Homebrew 或下载曲库。

这是离线打包目标与资源验证结果，尚未完成每种全新目标系统的断网首次安装验收；系统音频、显示驱动等基础环境仍须正常。初次制品与测试范围见[离线安装包记录](../test-runs/2026-11-15-desktop-offline-installers.md)，窗口唤起修订的四平台制品与发布状态见[修订构建记录](../test-runs/2026-11-15-desktop-window-activation-release.md)。

## 选择安装包

| 电脑 | 文件后缀/标识 | 系统范围 |
| --- | --- | --- |
| Mac，Apple M 系列芯片 | `aarch64.dmg` | macOS 15 或更新版本 |
| Mac，Intel 芯片 | `x64.dmg` | macOS 15 或更新版本 |
| Windows 电脑，Intel/AMD 64 位 | `x64-setup.exe` | 面向 Windows 10/11 x64；构建及安装测试使用 Windows Server 2022 |
| Linux 电脑，Intel/AMD 64 位 | `amd64.AppImage` | Ubuntu 24.04 / glibc 2.39 基线 |

Mac 可在“关于本机”查看芯片类型；本轮提供两个架构包，尚不是 Universal。Windows ARM、Linux ARM 和更老 Linux 发行版不在本轮范围内。

## 安装

先从旧版的托盘/菜单栏选择“退出”，再安装新版。默认关闭窗口只是隐藏到后台，并不等于退出。不要同时运行两个版本写同一份数据。

### macOS

1. 打开对应芯片的 DMG。
2. 将应用拖入“应用程序”，完成复制后从“应用程序”打开。
3. 本测试包尚未做 Developer ID 公证，系统可能提示开发者未验证。先确认来源和 SHA-256，再按系统提供的单个应用确认流程操作；不要关闭全局安全保护。若系统不允许打开，请保留完整提示反馈。

### Windows

2026-11-15 窗口唤起修订（源码 `5ae16f8`）补齐后台再次打开入口恢复原窗口的行为，并保留上一修订 `f838255` 的启动不弹出终端修复。版本号仍为 `0.1.0`，本轮重新构建 Mac 两种芯片、Windows 和 Linux 四个平台；请用包内 `runtime-manifest.json` 的 `commit` 区分新旧安装包。

1. 打开 `x64-setup.exe`，按安装向导完成安装。
2. 若本机缺少 WebView2，安装程序使用包内离线安装器处理，不需要另行下载。
3. 本测试包尚未做发行代码签名，系统可能显示未知发布者。请核对来源和 SHA-256；企业安全策略阻止安装时，不要绕过组织策略。

已装旧预览版：先从托盘选择“退出”，再运行修订版安装程序覆盖安装；不需要卸载、清空设置或删除累计遍数。若浏览器保留了旧 ZIP，请从下载页的“Windows 修订版”按钮重新下载，并核对页面上的新 SHA-256。修订版正常启动时只显示播放器，不再出现控制台；启用后台运行时，关闭播放器窗口仍会留在后台。

### Linux

在文件属性中赋予 AppImage 执行权限后打开；也可在下载目录执行：

```sh
chmod +x ./Starlight_Desktop_Preview_0.1.0_amd64.AppImage
./Starlight_Desktop_Preview_0.1.0_amd64.AppImage
```

若报 FUSE 挂载相关错误，可使用免挂载运行方式：

```sh
APPIMAGE_EXTRACT_AND_RUN=1 ./Starlight_Desktop_Preview_0.1.0_amd64.AppImage
```

若报 glibc 版本不满足，应核对系统是否符合上述基线，不要替换系统 glibc。该 AppImage 不是任意 Linux 版本通用包。

## 建议这样试用

1. 安装完成后断开网络，打开“列表”，分别试听曲目，重点检查 A04 和 A05。
2. 在“我的”设置重复遍数为 2，选择单曲播放，验证完成有效周期后停止；再检查其他三种模式。
3. 开关同步，确认同步开启时进度不可拖动；观察换遍并记录有无吞音。播放页已不再显示两句冗余说明。
4. 在“任务”先点立即播放，核对曲目、遍数、模式和同步配置；再设置一个稍后启用的任务。`0.1.1` 还可指定重复星期，操作见下节。
5. 关闭窗口，让应用留在后台，检查到点播放和托盘重新打开；电脑睡眠、关机或彻底退出时不保证任务执行。
6. 从托盘正常退出，再次打开，检查配置及完成遍数恢复，且不会自行开始播放。

首次使用默认“关闭窗口后留在后台”开启；已有安装保留之前的选择。“我的”中可以关闭此选项。关怀模式隐藏任务入口，但已经启用的任务仍有效。

### 0.1.1：按星期重复

1. 打开“任务”，点击“＋增加任务”或已有任务的信息区域。
2. 用已有的时、分、秒选择框设置启动时刻，在下面的“一 二 三 四 五 六 日”选择执行日期。
3. 高亮表示选中，可以多选；至少保留一天。新任务默认每天；旧任务升级后仍是每天，不改变开关状态。
4. 填写名称、曲目、遍数、模式和同步设置后保存。列表会显示“每天”“周末”或具体星期，保存不会立即播放；取消不会保存草稿。
5. 打开任务开关后只在所选星期自动执行。即使当天未选中或开关关闭，“立即播放”仍可使用。

相同时刻、星期不重叠的任务可以同时启用；星期重叠时会提示冲突。修改时刻或星期不会补播之前的任务。电脑必须保持运行，睡眠和退出的限制不变。

升级改名不要求清空设置或计数。安装前先从旧程序托盘彻底退出；因新旧应用显示名称不同，安装后请核对快捷方式和实际版本，避免仍打开旧文件。各平台的改名覆盖安装路径尚待新安装包验收。

### 后台运行时如何再次打开

以下为窗口唤起修订的操作约定；请确认包内源码修订是 `5ae16f8`（或后续包含该修复的提交），公开下载页是否已更新以发布记录为准：

| 场景 | 操作 |
| --- | --- |
| Windows 窗口关闭到后台 | 双击桌面快捷方式，或点击任务栏中的固定入口，恢复原窗口 |
| macOS 窗口关闭/隐藏/最小化 | 点击 Dock（程序坞）中的星光播放器，恢复原窗口 |
| Windows 托盘 / macOS 菜单栏图标 | 左键点击打开主窗口；右键点击显示操作菜单 |
| Linux 托盘 | 通过菜单选择“打开星光播放器”；左键行为取决于桌面环境 |

再次打开只显示原有窗口，保持正在播放的曲目、进度、遍数和任务，不重新开始播放。窗口已经显示时，再点入口也不会重复启动播放器。要真正停止后台播放与定时任务，请在托盘/菜单栏菜单选择“彻底退出（停止播放与定时任务）”。

旧版进程即使已经安装了新文件，也不会自动更新这些行为。升级后需从旧版菜单彻底退出，再打开新版；无需清空设置或累计遍数。验收情况见[窗口唤起测试记录](../test-runs/2026-11-15-desktop-window-activation.md)。

跨电脑同步还受设备时钟及音频输出延迟影响；构建通过不代表所有声卡、蓝牙或睡眠场景均已验证。
