# 电脑版测试预览：安装与试用

版本：`0.1.0`。这是独立的电脑版测试预览，不是手机版的新版本。

安装包已收录全部 21 首音频、libmpv 播放引擎及平台所需的非系统播放库。Windows 包还内置完整 WebView2 离线安装程序。不需要自行安装 Node、Rust、Homebrew 或下载曲库。

这是离线打包目标与资源验证结果，尚未完成每种全新目标系统的断网首次安装验收；系统音频、显示驱动等基础环境仍须正常。精确制品与测试范围见[本次安装包记录](../test-runs/2026-11-15-desktop-offline-installers.md)。

## 选择安装包

| 电脑 | 文件后缀/标识 | 系统范围 |
| --- | --- | --- |
| Mac，Apple M 系列芯片 | `aarch64.dmg` | macOS 15 或更新版本 |
| Mac，Intel 芯片 | `x64.dmg` | macOS 15 或更新版本 |
| Windows 电脑，Intel/AMD 64 位 | `x64-setup.exe` | 面向 Windows 10/11 x64；构建及安装测试使用 Windows Server 2022 |
| Linux 电脑，Intel/AMD 64 位 | `amd64.AppImage` | Ubuntu 24.04 / glibc 2.39 基线 |

Mac 可在“关于本机”查看芯片类型；本轮提供两个架构包，尚不是 Universal。Windows ARM、Linux ARM 和更老 Linux 发行版不在本轮范围内。

## 安装

先从旧版的托盘/菜单栏选择“退出”，再安装新版。默认关闭窗口只是隐藏到后台，并不等于退出。不要同时运行两个版本写同一份数据。

### macOS

1. 打开对应芯片的 DMG。
2. 将应用拖入“应用程序”，完成复制后从“应用程序”打开。
3. 本测试包尚未做 Developer ID 公证，系统可能提示开发者未验证。先确认来源和 SHA-256，再按系统提供的单个应用确认流程操作；不要关闭全局安全保护。若系统不允许打开，请保留完整提示反馈。

### Windows

1. 打开 `x64-setup.exe`，按安装向导完成安装。
2. 若本机缺少 WebView2，安装程序使用包内离线安装器处理，不需要另行下载。
3. 本测试包尚未做发行代码签名，系统可能显示未知发布者。请核对来源和 SHA-256；企业安全策略阻止安装时，不要绕过组织策略。

### Linux

在文件属性中赋予 AppImage 执行权限后打开；也可在下载目录执行：

```sh
chmod +x ./Starlight_Desktop_Preview_0.1.0_amd64.AppImage
./Starlight_Desktop_Preview_0.1.0_amd64.AppImage
```

若报 FUSE 挂载相关错误，可使用免挂载运行方式：

```sh
APPIMAGE_EXTRACT_AND_RUN=1 ./Starlight_Desktop_Preview_0.1.0_amd64.AppImage
```

若报 glibc 版本不满足，应核对系统是否符合上述基线，不要替换系统 glibc。该 AppImage 不是任意 Linux 版本通用包。

## 建议这样试用

1. 安装完成后断开网络，打开“列表”，分别试听曲目，重点检查 A04 和 A05。
2. 在“我的”设置重复遍数为 2，选择单曲播放，验证完成有效周期后停止；再检查其他三种模式。
3. 开关同步，确认同步开启时进度不可拖动；观察换遍并记录有无吞音。播放页已不再显示两句冗余说明。
4. 在“任务”先点立即播放，核对曲目、遍数、模式和同步配置；再设置一个稍后启用的任务。
5. 关闭窗口，让应用留在后台，检查到点播放和托盘重新打开；电脑睡眠、关机或彻底退出时不保证任务执行。
6. 从托盘正常退出，再次打开，检查配置及完成遍数恢复，且不会自行开始播放。

首次使用默认“关闭窗口后留在后台”开启；已有安装保留之前的选择。“我的”中可以关闭此选项。关怀模式隐藏任务入口，但已经启用的任务仍有效。

跨电脑同步还受设备时钟及音频输出延迟影响；构建通过不代表所有声卡、蓝牙或睡眠场景均已验证。

## 遇到问题

请记录系统版本、芯片/架构、安装包文件名，以及问题发生的操作、时间、曲目、重复遍数、播放模式和同步开关状态。

普通模式下在“我的”导出诊断。日志可能包含任务名称、播放习惯和本地路径，发送前请检查隐私。不要为了排错删除计数或应用数据。

如需回退，先正常退出新版，保留数据和旧安装包，再安装旧测试包。不要同时打开两个版本。本次更新不要求清空原有预览数据。
