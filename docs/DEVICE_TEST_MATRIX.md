# 设备与发布候选测试矩阵

> 最后核对：2026-10-16；已有源码级证据对应 commit `0698f629376c73b8daee3aa7fbdaf2af1c63b29c`。此文档定义覆盖要求并摘要已有证据；没有记录的场景一律视为未验证。每个候选的逐项实际结果必须单独写入 [`test-runs/`](test-runs/README.md)，不能直接改写本矩阵来代替执行记录。

## 1. 状态定义

| 状态    | 含义                                                           |
| ------- | -------------------------------------------------------------- |
| PASS    | 指定 build 在指定设备/系统上按用例完成，并有日期、操作者和证据 |
| PARTIAL | 仅完成启动、截图或部分流程，不能外推到完整功能                 |
| FAIL    | 可复现地不满足验收标准，必须有问题编号                         |
| BLOCKED | 因二进制、设备、账号或外部条件无法执行                         |
| NOT RUN | 尚未测试                                                       |

模拟器通过不能替代真机；用户反馈也不能自动等同于结构化回归 PASS。

## 4. 核心功能用例

每个候选平台至少执行下表；测试中同时观察声音、当前曲目、当前遍数、总遍数、统计、日志和重启后的持久化，不能只听“是否在播放”。

| ID  | 场景              | 关键验收                                                                                  |
| --- | ----------------- | ----------------------------------------------------------------------------------------- |
| P01 | 单曲播放，N=1     | 一遍有效周期后停止；再次播放创建新任务，从第 1 遍开始                                     |
| P02 | 单曲播放，N=7     | 完成 7 遍才停止，中途不得提前执行模式                                                     |
| P03 | 单曲循环，N=1/7   | 达 N 后继续同曲；累计显示连续增长，模式 session 正确归零                                  |
| P04 | 列表播放，N=2     | 每首完成 2 遍才换下一首；换曲后新任务累计数清零；最后一首停止                             |
| P05 | 列表循环，N=2     | 每首完成 2 遍；换曲后新任务累计数清零；末尾回到第一首                                     |
| P06 | 快捷遍数          | 1、108、1,000、10,000 可选中并持久化                                                      |
| P07 | 自定义大数        | 5,000,000 可输入、显示千分位、重启保留；空值/0/超安全整数拒绝；核对非数字粘贴后的转换结果 |
| P08 | 手动重选当前曲    | 视为新播放任务，累计遍数清零                                                              |
| P09 | 主动关闭/意外退出 | 重开同一任务后继续最后已完成遍数，不重复或丢计数                                          |
| P10 | 高频操作          | 连续播放/暂停、上下首、模式、同步不会交错换错曲或重复计数                                 |

## 5. 同步模式用例

| ID  | 场景                 | 关键验收                                                                 |
| --- | -------------------- | ------------------------------------------------------------------------ |
| S01 | 从中间加入           | 对齐到墙钟位置且尾段不计数；无累计的新任务显示 0，已有任务保留原累计数   |
| S02 | 自然换遍             | QueueEnded 后重新按当前墙钟对齐；落在 0～1.5 秒取得下一遍资格            |
| S03 | 暂停后恢复           | 短暂停按位移规则保留资格；长暂停重新对齐且不错误计完整遍                 |
| S04 | App/锁屏 seek        | 同步开启时 App 进度和远程 seek 均被锁定/纠正                             |
| S05 | 两台同型号设备       | 同曲同时间启动，记录 10 分钟与多个周期后的听感/日志偏差                  |
| S06 | iOS + Android 跨平台 | 同时播放 A05、A04 和长曲，记录周期边界与漂移                             |
| S07 | 时钟/时区异常        | 明确设备时间或时区不同会不同步，恢复正确时钟后能重新对齐                 |
| S08 | A05 专项             | 至少自然完成 21 遍，记录每个 QueueEnded、seek 目标、实际起点和是否吞首音 |
| S09 | 其余 20 首抽样/全量  | 每首至少完成一次同步自然换遍，确认 A05 修复没有掩盖普遍问题              |

多设备测试前应启用系统自动时间，记录各设备时区和系统时间偏差。同步使用设备本地当天 00:00 基准，不使用服务器校时。

## 6. 生命周期、系统控制与硬件

| ID  | 场景                   | 真机要求                                               |
| --- | ---------------------- | ------------------------------------------------------ |
| L01 | 锁屏 30 分钟           | 音频持续、曲目信息正确、允许的按钮与业务状态一致       |
| L02 | Android 切后台/划掉 UI | 继续播放；重新进入接管原生队列，不清零任务             |
| L03 | Android 厂商省电       | 默认/严格省电分别记录；被系统杀死时给出真实限制和引导  |
| L04 | iOS 后台 30 分钟       | 后台音频持续，返回后 UI 与原生状态一致                 |
| L05 | 来电/系统音频中断      | 暂停与恢复符合用户意图，不把不连续尾段计为完整遍       |
| L06 | 其他 App 抢音频焦点    | 不意外自启；期望播放时可恢复并保留正确资格             |
| L07 | 有线/蓝牙断开          | 暂停/恢复符合平台规范，远程上下首和播放/暂停正确       |
| L08 | Service/进程重建       | 曲目索引、模式、累计遍数和 `expected_playing` 正确恢复 |
| L09 | 诊断导出               | `.txt` 完整、系统分享可取消/完成、不假报成功           |
| L10 | 连续运行               | A05 21 遍、长曲和列表至少 2 小时，无自动停止和计数漂移 |

模拟器只能辅助 L08/L09 的部分分支；L01～L07 必须用真机。

## 8. 安装、升级与资源

发布候选必须分别测试：

- 全新安装：默认同步开启、重复 1、单曲循环、关怀关闭。
- 从最后公开版本 0.6.0 升级到当前版本：设置迁移、曲目、播放任务和统计不崩溃。
- 从小范围 0.7.0 升级：旧 `last_track_id`/`started_from_zero` 数据兼容。
- Android release APK 与商店 AAB 生成的安装包；Debug 通过不能替代 release。
- iOS TestFlight/App Store build；Development IPA 通过不能替代 distribution build。
- 21 首音频逐首能开始播放，文件名/时长/双端哈希通过 `docs/AUDIO_ASSETS.md` 检查。
- 无网络启动和完整播放；当前业务不依赖服务器。

## 10. 证据采集与隐私

Android 基础信息：

```bash
adb shell getprop ro.product.manufacturer
adb shell getprop ro.product.model
adb shell getprop ro.build.version.release
adb shell getprop ro.build.version.sdk
adb shell wm size
adb shell dumpsys package com.starlightplayer | rg 'versionCode=|versionName='
```

iOS Simulator 清单和截图尺寸：

```bash
xcrun simctl list devices available
sips -g pixelWidth -g pixelHeight /absolute/path/to/screenshot.png
```

App 内优先使用“我的 → 诊断信息 → 导出诊断文件”。系统 bugreport、Console/sysdiagnose 可能包含设备标识、其他 App、路径、账号或通知内容；上传前必须由测试者审阅、脱敏，并存入受控位置。不得把用户诊断原文直接提交到公开仓库。
